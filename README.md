# Personal Portfolio Website

A responsive portfolio website for Muhammad Hashim, a full-stack engineer. It shows skills, projects, education, and contact details.

**Live site:** https://hashim017.github.io/auspify-portfolio/

## Features

- Responsive design for phone, tablet, and desktop
- Home, About, Skills, Projects, and Contact sections
- Project showcase with 8 projects, tech tags, live demos, and GitHub links
- Working contact form using Formspree
- Mobile menu, smooth scrolling, and scroll animations
- Dark modern theme

## Tech Used

- HTML5
- CSS3 with Flexbox, Grid, and CSS variables
- JavaScript
- Formspree for the contact form
- GitHub Pages for hosting

## Run Locally

1. Clone the repo.
2. Open the folder in VS Code.
3. Right-click `index.html` and choose "Open with Live Server".
