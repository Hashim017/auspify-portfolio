## 📖 About

This is my personal portfolio website. It introduces who I am, lists my skills and links to my best projects. It was built as Task 1 of the Auspify internship.

## 🚀 Features

| Feature | Description |
|---|---|
| Responsive design | Works on phone, tablet and desktop |
| Four pages | Home, About, Projects and Contact |
| Project showcase | Cards with links to each GitHub repo |
| Contact form | Visitors can send me a message |
| Smooth navigation | Clean menu and page transitions |

```bash

cd auspify-portfolio
```

Open `index.html` in your browser. No build step is needed.
